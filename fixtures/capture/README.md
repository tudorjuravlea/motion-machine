# fixtures/capture

Pinned inputs for the motion-capture tests (`tests/capture/`).

- `site/` is a small page the brand-capture tests read.
- `reference/*.mp4` are rendered films, kept so the tests read a fixed video instead of rendering one
  first. They are test inputs, not deliverables, and are the only videos the repository tracks.
  - `cuts`, `single`, `kinds` and the `tempo-*` films are generated by `reference/render.mjs` from
    the pieces under `reference/pieces/`, so the cut instants come from the kit's own schedule.
  - `golden-film-*-16x9.mp4` are 16x9 exports of `pieces/golden-film-kinetic` and
    `pieces/golden-film-editorial` (`node scripts/mm.mjs export pieces/golden-film-kinetic`).

To regenerate the first group, run `node fixtures/capture/reference/render.mjs` (it needs Chromium
and ffmpeg); pass a name such as `cuts` or `tempo-a:calm` to render one. Commit a new film only when
the capture tests need a new reference.
